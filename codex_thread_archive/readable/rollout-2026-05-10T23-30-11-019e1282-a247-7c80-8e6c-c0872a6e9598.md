# Escalation Requests

Commands are run outside the sandbox if they are approved by the user, or match an existing rule that allows it to run unrestricted. The command string is split into independent command segments at shell control operators, including but not limited to:

- Pipes: |
- Logical operators: &&, ||
- Command separators: ;
- Subshell boundaries: (...), $(...)

Each resulting segment is evaluated independently for sandbox restrictions and approval requirements.

Example:

git pull | tee output.txt

This is treated as two command segments:

["git", "pull"]

["tee", "output.txt"]

Commands that use more advanced shell features like redirection (>, >>, <), substitutions ($(...), ...), environment variables (FOO=bar), or wildcard patterns (*, ?) will not be evaluated against rules, to limit the scope of what an approved rule allows.

可以把这张图理解成一个“低分辨率像素龙虾”，核心不是画曲线，而是先把图拆成网格，再用红色方块堆出轮廓、阴影和高光。

**设计思路**

1. **建立像素网格**
   建议用 `31 x 31` 或 `33 x 33` 的正方形网格。每个像素块可以是 `18px - 28px`，根据页面大小缩放。

   画布结构可以是：

   ```text
   白色背景
   中间放一个 CSS Grid
   每个格子是一个 div
   有颜色的格子显示为红色方块
   空格子透明
   ```

2. **先画主体轮廓**
   这只龙虾大致是左右对称的，可以从中线开始画。

   主体分成几块：

   ```text
   触角：顶部两条向外弯的细线
   头部：中上方红色大矩形
   眼睛：头部左右两颗黑色方块
   身体：中下方较宽的腹部
   尾巴：底部小扇形结构
   左右钳子：上方两侧大红色爪子
   左右手臂：从身体两侧弯向钳子
   小脚：身体两侧几组短折线
   ```

3. **使用左右镜像**
   这张图最重要的特征是对称。

   可以只设计左半边坐标，然后用程序自动镜像到右边：

   ```js
   mirrorX = gridWidth - 1 - x
   ```

   这样左钳子、左手臂、左脚画好后，右边自动生成，风格会更统一。

4. **颜色分层**
   不要只用一种红色。至少准备 5 个色阶：

   ```css
   --dark: #b80000;      /* 最深阴影 */
   --red: #e00000;       /* 外轮廓 */
   --main: #ff1a0a;      /* 主体红 */
   --light: #ff4a22;     /* 高光 */
   --black: #050505;     /* 眼睛 */
   ```

   用法：

   ```text
   深红：钳子边缘、手臂底部、尾巴阴影
   正红：主体外形
   亮红/橙红：头部中央、钳子内侧、尾巴中间
   黑色：两只眼睛
   ```

5. **主体像素结构**
   可以按这个比例画：

   ```text
   第 5-10 行：左右钳子
   第 7-12 行：触角和钳子连接
   第 11-18 行：头胸主体
   第 15-20 行：手臂和小脚
   第 19-24 行：腹节
   第 24-27 行：尾巴
   ```

6. **龙虾头部**
   头部是一个竖向圆角感的像素矩形，但不能真的用圆角，要用方块错位表现。

   示例结构：

   ```text
       █████
      ███████
      ███████
      ███████
       █████
   ```

   左右各放一个黑色方块作为眼睛：

   ```text
   █ 黑 ███ 黑 █
   ```

7. **钳子画法**
   钳子是整张图最有识别度的部分。不要画成圆形，而是用“阶梯形大夹子”。

   左钳子结构可以拆成：

   ```text
      ██  ██
     ███  ██
    ███████
    █████
     ████
      ██
   ```

   然后右侧镜像。

8. **触角画法**
   触角是两条从头顶伸出的折线：

   ```text
   左触角：从头顶左侧开始，向左上折两次
   右触角：镜像
   ```

   只需要单格宽度，用深红或正红即可。

9. **腿部画法**
   小脚不要太复杂，每边 3 组短折线就够：

   ```text
   身体左侧伸出一格
   向下错一格
   再向外一格
   ```

   看起来像像素化的关节。

10. **阴影和高光**
   这张图虽然是像素风，但有轻微体积感。可以在主体中间和钳子内侧加亮色块：

   ```text
   头部右上：亮红
   主体中间：一两个橙红高光块
   腹部中间：亮红横条
   钳子内侧：亮红块
   外侧边缘：深红块
   ```

**HTML实现方案**

最适合用 `CSS Grid + div`：

```text
1. 定义一个二维数组
2. 0 表示空白
3. 1 表示深红
4. 2 表示主红
5. 3 表示亮红
6. 4 表示黑色
7. JS 根据数组生成 div
8. 每个 div 根据数字设置背景色
```

这样后续很容易换颜色、导出、随机生成不同像素龙虾。

**推荐画布参数**

```text
网格：31 x 31
像素块：24px
背景：白色
主体居中
不加边框
方块之间无间距
整体可用 transform: scale() 做响应式缩放
```

一句话总结：先用 `31x31` 网格画出左右对称的大轮廓，再用 5 个红色色阶做体积，黑色方块做眼睛，钳子和触角用阶梯形像素线表现，这样就能用 HTML 方块还原这张图的核心视觉。

## [ASSISTANT]
要精准匹配，核心流程是：**把原图先量化成固定网格，再从每个网格格子的中心或平均区域采样颜色**。不要凭眼睛手工选色。

**推荐方法**

1. **确定网格尺寸**
   先判断原图实际像素风分辨率，比如这张图可以尝试：

   ```text
   31 x 31
   32 x 32
   33 x 33
   ```

   如果每个方块边缘能对齐，说明网格尺寸正确。

2. **把原图缩小到网格大小**
   用浏览器 Canvas 把图片缩小成 `31x31` 或 `33x33`。

   关键点是关闭平滑：

   ```js
   ctx.imageSmoothingEnabled = false;
   ```

   这样每个缩小后的像素就对应一个 HTML 方块。

3. **读取每个像素的 RGBA**
   Canvas 可以直接取颜色：

   ```js
   const data = ctx.getImageData(0, 0, gridW, gridH).data;
   ```

   每个格子的颜色是：

   ```js
   const i = (y * gridW + x) * 4;
   const r = data[i];
   const g = data[i + 1];
   const b = data[i + 2];
   const a = data[i + 3];
   ```

4. **过滤背景**
   因为原图背景接近白色，可以把接近白色的格子当作透明：

   ```js
   if (r > 245 && g > 245 && b > 245) {
     color = "transparent";
   }
   ```

5. **输出颜色矩阵**
   最终生成一个二维数组：

   ```js
   [
     ["", "", "#d70000", "#ff2a12"],
     ["", "#c60000", "#ff1b0a", ""]
   ]
   ```

   HTML 按这个矩阵渲染，每个格子的位置就是原图位置。

**更精准的采样方式**

不要只取格子中心点，最好取每个格子的平均颜色：

```js
function averageCellColor(sourceCtx, x, y, cellW, cellH) {
  const img = sourceCtx.getImageData(x * cellW, y * cellH, cellW, cellH).data;
  let r = 0, g = 0, b = 0, a = 0, count = 0;

  for (let i = 0; i < img.length; i += 4) {
    r += img[i];
    g += img[i + 1];
    b += img[i + 2];
    a += img[i + 3];
    count++;
  }

  return {
    r: Math.round(r / count),
    g: Math.round(g / count),
    b: Math.round(b / count),
    a: Math.round(a / count)
  };
}
```

**最终实现逻辑**

```text
上传原图
设置网格尺寸，比如 31x31
Canvas 读取图片
按网格切块
每块计算平均颜色
接近白色的块设为透明
生成 HTML div 方块
导出颜色矩阵
```

这样可以做到：

```text
位置精准：第 x 列第 y 行对应原图同一区域
颜色精准：每个方块来自原图采样
结构精准：不会靠人工猜轮廓
```
