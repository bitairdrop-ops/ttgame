## 🎮 应用需求文档：闪玩（FlashPlay）

### 一、产品定位

| 维度 | 定义 |
|------|------|
| **产品名称** | 闪玩（FlashPlay） |
| **Slogan** | 3秒生成，刷着玩 |
| **核心定位** | AI驱动的UGC休闲游戏平台 |
| **目标用户** | Z世代、碎片化时间用户、轻度游戏爱好者 |
| **竞品参考** | 抖音（交互模式）、Poki（游戏聚合）、AI Dungeon（生成） |

---

### 二、核心功能架构

```
┌─────────────────────────────────────────────────────────┐
│  【首页】刷游戏模式（核心入口）                            │
│  ├── 上下滑动切换游戏（类抖音feed流）                      │
│  ├── 游戏自动加载，即点即玩                               │
│  └── 智能推荐算法（停留时长、点赞、分享）                  │
├─────────────────────────────────────────────────────────┤
│  【生成页】AI创作中心                                     │
│  ├── 文字输入框（想法描述）                               │

├─────────────────────────────────────────────────────────┤
│  【发现页】游戏库                                         │
│  ├── 分类浏览（益智/动作/解压/创意）                      │
│  ├── 热门榜单（日榜/周榜/总榜）                           │

└─────────────────────────────────────────────────────────┘
```

### 三、核心功能详解

#### 3.1 刷游戏模式（Feed流）

| 交互设计 | 说明 |
|---------|------|
| **手势** | 上滑下一款、下滑上一款、双击点赞、长按收藏 |
| **游戏加载** | 预加载下3款，当前游戏首屏<1秒启动 |
| **单局时长** | 控制在30秒-3分钟，支持"再来一局" |
| **无缝切换** | 退出当前游戏不中断，后台保留进度 |

**界面布局：**
```
┌─────────────────┐
│  [游戏画面]      │  ← 全屏沉浸，顶部有半透明状态栏
│                 │
│  [玩法提示]      │  ← 首次出现显示3秒消失
│                 │
│  ━━━━━━━━━━━━━  │  ← 底部进度条（单局剩余时间）
│  👤 创作者名称   │
│  📝 "躲避障碍吃金币"  │  ← 游戏描述
│  ❤️ 1.2w  💬 340  ↗️ │
└─────────────────┘
     [⬆️] [⬇️] 导航箭头
```

#### 3.2 AI游戏生成器

**输入方式：**
- 文字描述（必填）："做一个猫咪接鱼的小游戏"
- 风格选择（选填）：像素风/手绘风/3D卡通/极简
- 难度调节（选填）：简单/中等/困难

**生成流程：**
```
用户输入 → AI解析意图 → 生成游戏代码 → 实时预览 → 用户确认发布
  (3秒)      (10秒)        (15秒)        (2秒)      (即时)
```

**生成示例：**

| 用户输入 | AI生成结果 |
|---------|-----------|
| "解压游戏，捏泡泡" | 泡泡纸模拟器：点击泡泡破裂，ASMR音效 |
| "考验反应，别踩白块" | 节奏点击：黑块前进，错过即失败 |
| "物理弹射，打砖块" | 弹球游戏：带重力感应，砖块有不同硬度 |
| "双人对抗，抢金币" | 分屏对战：同屏竞技，先拿10个胜 |

### 四、技术架构

| 模块 | 技术方案 |
|-----|---------|
| **游戏引擎** | 轻量级WebGL（Pixi.js/Phaser）或自研Runtime |
| **AI生成** | 多模态大模型（游戏逻辑→代码生成） |
| **Feed流** | 类抖音推荐算法（协同过滤+内容理解） |
| **存储** | 游戏代码云端存储，本地缓存热门游戏 |
| **性能** | 游戏包<500KB，首屏加载<1秒 |

---

### 五、商业模式

| 模式 | 说明 |
|-----|------|
| **广告变现** | 游戏间插屏广告、激励视频（复活/提示） |
| **创作者分成** | 游戏播放量收益，激励UGC |
| **会员订阅** | 去广告、专属生成模板、优先审核 |
| **IP合作** | 品牌定制小游戏（如"三消领优惠券"） |

---

### 六、差异化亮点

1. **零门槛创作**：不需要编程，一句话生成可玩游戏
2. **刷视频式体验**：降低决策成本，被动消费内容
3. **即时反馈**：生成→试玩→分享，全流程<1分钟
4. **病毒传播**：游戏自带分享点（"挑战好友分数"）

---

### 七、MVP功能清单

| 优先级 | 功能 | 说明 |
|-------|------|------|
| P0 | 刷游戏Feed流 | 核心交互，必须流畅 |
| P0 | 文字生成游戏 | 至少支持3种基础类型（点击/躲避/收集） |
| P1 | 点赞/分享/收藏 | 社交互动基础 |
| P1 | 创作者主页 | 展示个人作品 |
| P2 | 游戏编辑器 | 简单调整参数（颜色、速度） |
| P2 | 排行榜 | 日榜/好友榜 |

这个产品的核心价值在于**"生成即消费"**的闭环——用户既是消费者也是生产者，刷游戏的低门槛体验能最大化留存，而AI生成能力解决了UGC平台最大的内容供给问题。
