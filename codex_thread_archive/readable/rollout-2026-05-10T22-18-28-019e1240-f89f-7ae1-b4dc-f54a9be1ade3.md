# Escalation Requests

Commands are run outside the sandbox if they are approved by the user, or match an existing rule that allows it to run unrestricted. The command string is split into independent command segments at shell control operators, including but not limited to:

- Pipes: |
- Logical operators: &&, ||
- Command separators: ;
- Subshell boundaries: (...), $(...)

Each resulting segment is evaluated independently for sandbox restrictions and approval requirements.

Example:

git pull | tee output.txt

This is treated as two command segments:

["git", "pull"]

["tee", "output.txt"]

Commands that use more advanced shell features like redirection (>, >>, <), substitutions ($(...), ...), environment variables (FOO=bar), or wildcard patterns (*, ?) will not be evaluated against rules, to limit the scope of what an approved rule allows.

## [ASSISTANT]
可以做成一个 **CodexMint ETH NFT**：AI/Agent 参与生成和解释，但真正 mint 仍由用户钱包确认。

**核心定位**
CodexMint 不是“AI 自动拿你钱包 mint”，而是一个 ETH NFT mint 助手：

```text

Next.js + TypeScript + wagmi + viem + RainbowKit

Smart Contract
Solidity + Foundry + OpenZeppelin ERC721 / ERC721A

AI / Codex Layer
本地 Codex 助手或后端 agent
负责解释、检查、生成参数、辅助排错
不接触私钥

Optional Backend
Node.js / Hono / Next API
用于 allowlist、metadata、签名校验、mint 状态缓存

IPFS / Arweave / Pinata
存 NFT image + metadata

function mint(uint256 quantity) external payable {

    require(minted[msg.sender] + quantity <= MAX_PER_WALLET, "Wallet limit");
    require(msg.value == PRICE * quantity, "Wrong ETH");

    minted[msg.sender] += quantity;
    _safeMint(msg.sender, quantity);
}
```

- “交易失败原因是什么”
- “mint 后你的 NFT 在哪里看”

**它做什么**

2. 检查是否连接钱包。
3. 检查当前网络是否正确，例如 Ethereum / Base / Arbitrum / Polygon。
4. 读取 mint 价格、剩余 supply、单钱包限制、mint 状态。
5. 帮用户判断这次 mint 要花多少 ETH。
6. 解释钱包弹窗里的交易内容。

9. 展示 tx hash、mint 成功状态、NFT 链接。

# NFT Mint Assistant

Use this skill when the user wants to mint an already live NFT collection.

## Scope

This skill helps users safely mint NFTs from existing mint pages or deployed NFT contracts.

It focuses on:
- identifying the official mint source
- checking contract and chain information
- reading mint price and supply state
- explaining wallet transaction details
- helping the user complete wallet-confirmed minting
- verifying the transaction result

## Non-Goals

Do not create NFT contracts.
Do not build NFT mint sites.
Do not deploy contracts.
Do not ask for private keys or seed phrases.
Do not auto-sign transactions.
Do not guarantee profit or rarity.
Do not encourage minting without risk explanation.

## Safety Boundary

The assistant can inspect, explain, and prepare.
The user's wallet must confirm every transaction.
The assistant must never request private keys, seed phrases, or raw wallet credentials.

## Required Inputs

Try to get at least one of:
- official mint page URL
- contract address
- collection name
- chain name
- marketplace page
- project X/Twitter or Discord link

## Mint Verification Checklist

Before minting, check:

- Is the URL likely official?
- Is the contract address visible?
- Is the chain correct?
- Is the contract verified?
- Is mint currently open?
- What is the mint price?
- What is the max mint quantity?
- What is the total supply and remaining supply?
- Is this a direct mint or marketplace purchase?
- Does the wallet popup match the expected price and contract?
- Is the transaction only minting, or does it request approval?

## User Flow

1. Ask user for mint page URL or contract address.
2. Identify chain and contract.
3. Read or infer mint function.
4. Explain price, gas, and quantity.
5. Warn about suspicious signs.
6. Ask user to connect wallet on the official page.
7. User clicks mint.
8. User confirms in wallet.
9. Verify transaction hash.
10. Show final result.

## Transaction Explanation

When the wallet opens, explain:
- recipient contract
- ETH amount
- gas estimate
- function name if visible
- quantity
- chain
- whether approval is being requested

## Red Flags

Warn the user if:
- URL is not official
- contract address is hidden or different from official links
- wallet popup asks for unexpected approval
- ETH amount differs from displayed mint price
- contract is unverified
- mint function is unusual
- page asks for seed phrase
- page asks to download unknown software
- collection has many clone sites
