```bash

  --backend onnx \

  --output /Users/vincet/Documents/aiglass/aigame/tmp/moss-tts-female.wav

**2. 用参考音频做音色克隆**
这是更可靠的女声方案。准备一段女声参考音频，比如 `female_ref.wav`，然后：

```bash
/Users/vincet/Documents/aiglass/aigame/.venv-moss-tts/bin/moss-tts-nano generate \
  --backend onnx \

- 只是快速换声音：先找 `--voice` preset
